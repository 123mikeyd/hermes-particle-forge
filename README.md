# Particle Forge V2 Cool Pass

Standalone browser-based math-art particle forge.

## Open locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8765
```

Then visit `http://127.0.0.1:8765/`.

## V2 Cool Pass features

- Formula worlds: Trig Bloom, Jellyfish, Rose, Lissajous, Phyllotaxis, De Jong, Fireflies, Polar Sine Orbitals, Lorenz Spiral Attractor
- Curated Scene Presets:

- Palette Worlds:

- Trail Materials:
